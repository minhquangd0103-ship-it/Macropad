# Macropad sayo device
My Sayo Device is a 3 key macropad with an OLED display that uses QMK firmware. Its main purpose is to be a high reactive key to help me get better at Geometry Dash. It can be reprogrammed with any keys which in my case are: up arrow, Spacebar and up arrow.
# Features:
- 3 keys
- 128x32 OLED display
# CAD Model:
Everything sticks together using 4 M3 Bolts and heatset inserts. It has 2 differents printed parts: top and bottom. I used Onshape use since it was easier than Fusion360.

# BOM

- 4x M3x5mx4mm heatset inserts

- 6x 1N4148 DO-35 Diodes
- 1x Seeed XIAO RP2040
- 1x Case (2 printed parts)
